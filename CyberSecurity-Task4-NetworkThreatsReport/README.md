Common Network Security Threats

About This Project

This project is a research report prepared as part of the Oasis Infobyte Security Analyst Internship.

Objective

The objective of this report is to understand common network security threats, how they work, their real-world impact, and the security measures used to prevent them.

Topics Covered

- Denial-of-Service (DoS) and Distributed Denial-of-Service (DDoS) Attacks
- Man-in-the-Middle (MITM) Attacks
- IP Spoofing
- DNS Poisoning and Spoofing

Tools Used

- Markdown
- GitHub
Report Structure

The detailed report includes explanations, real-world examples, impacts, and prevention methods for each network security threat.

Conclusion

This project helps develop awareness of network security risks and the importance of protecting computer networks from cyberattacks.
